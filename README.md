# Telegram Bot — система приёма заявок

Telegram-бот для автоматизированного приёма и управления заявками клиентов.

## Возможности

### Для пользователей
- Выбор интересующей услуги.
- Пошаговое заполнение заявки.
- Проверка введённых данных.
- Подтверждение отправки.
- Отмена заполнения через `/cancel`.
- Уведомление об успешной отправке.

### Для администратора
- Просмотр последних заявок через `/admin`.
- Просмотр подробной информации.
- Изменение статуса заявки.
- Статусы: «Новая», «В работе», «Завершена».
- Уведомления о новых заявках.

## Технологии

- Python
- python-telegram-bot
- SQLite
- python-dotenv
- Telegram Bot API

## Установка

1. Склонируйте репозиторий.
2. Создайте виртуальное окружение.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Создайте файл `.env`:

```env
BOT_TOKEN=your_bot_token
ADMIN_ID=your_telegram_id
```

5. Запустите бота:

```bash
python main.py
```

## База данных

Для хранения заявок используется SQLite. База создаётся автоматически при первом запуске.

## Назначение проекта

Демонстрационный проект для портфолио. Показывает навыки разработки Telegram-ботов, работы с базами данных, обработки пользовательского ввода и реализации административного интерфейса.
